# Screenshots

One screenshot of every screen in *Where in the World is Clara San Diego?* (Android), taken on the
`Pixel_6_API_34` emulator (2400×1080, landscape) with the **paid World Campaign entitlement active**.
The build is a debug build, so the menu bar also shows a developer-only **Debug** menu. It is not
in release builds. The detective in these shots is named "Ada".

## Not captured

- **Purchase offer / unlock ceremony**: a paid account never sees the purchase dialog. The
  one-time "World Campaign unlocked" ceremony appears only right after a real Play purchase.
- **Variations of screens above**, such as other cities, witnesses, suspects and database entries,
  the other tutorial steps, the wrong-warrant or out-of-time result, and the Y/N first-day prompt
  at sign-on.
- The Android system share sheet and notification-permission prompt are system UI, not game screens.
