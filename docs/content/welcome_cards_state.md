## Conventions (how these cards work)
- Each card = an **arrival blurb** (shown when the player lands; encyclopedic, kid-friendly) + up to **5 clues** + a **say-hello** learn line.
- A **clue** is a subject-less, past-tense phrase describing something the *suspect* said/did, pointing to where they fly **next**. Rendered in-game as "The suspect " + phrase; the game supplies the witness + real name. Never names a witness; non-flag/money clues never state the country name; traveler-logic (a visitor, never a local's identity); concrete/kid-friendly, no dry stats.
- Exactly **one flag** clue per card (never dropped). A **money** clue only when the country has its own (non-shared) currency, as a pre-trip scenario (never "paid with X").
- Cards may have **fewer than 5 clues** on purpose — the reviewer trims lesser-known countries to 2–4 clues (keeping the flag) to make them easier to guess.
